# Sherwood Labs

**Open-source tooling, bots, and apps for Robinhood Chain.**

SDKs, launchpads, trading automation, and on-chain analytics, built in the open.

---

## 🧰 Developer Tooling

| Repository | Description |
|---|---|
| [robinhood-chain-sdk-typecript](https://github.com/sherwood-labs/robinhood-chain-sdk-typecript) | Community TypeScript SDK on viem for Robinhood Chain: Stock Tokens, USDG, Uniswap v3 swaps, launchpads, and the sequencer feed. |
| [robinhood-chain-toolkit](https://github.com/sherwood-labs/robinhood-chain-toolkit) | Dependency-free TypeScript library for tokenized-stock apps: share conversion, oracle checks, and pre-signing transaction review. |
| [robinhood-chain-wallet-onboarding](https://github.com/sherwood-labs/robinhood-chain-wallet-onboarding) | Wallet discovery (EIP-6963), chain setup (EIP-3085), and gas funding with React, custom element, and wagmi entry points. |
| [robinhood-chain-starter](https://github.com/sherwood-labs/robinhood-chain-starter) | Foundry starter with example contracts and deploy scripts for mainnet and testnet. |
| [robinhood-chain-dapp](https://github.com/sherwood-labs/robinhood-chain-dapp) | Example dapp for minting and redeeming tokenized-stock index basket shares. |

## 🚀 Launchpads

| Repository | Description |
|---|---|
| [robinhood-agent-launchpad](https://github.com/sherwood-labs/robinhood-agent-launchpad) | Launch tokens through a chat agent, then trade, swap, and track them from a wallet dashboard. |
| [robinhood-leveraged-launchpad](https://github.com/sherwood-labs/robinhood-leveraged-launchpad) | Coins backed by leveraged perp baskets, funded by a Uniswap v4 hook fee, with buyback and burn. |
| [robinhood-fair-launchpad](https://github.com/sherwood-labs/robinhood-fair-launchpad) | Fair-launch bonding curves paired with ETH or stock tokens, plus NFT collection mints. |

## 🤖 Trading Bots & Agents

| Repository | Description |
|---|---|
| [robinhood-ai-crypto-agent](https://github.com/sherwood-labs/robinhood-ai-crypto-agent) | Multi-agent crypto trading desk for Robinhood Agentic accounts, with a code-enforced risk gate. |
| [robinhood-sniper-bot](https://github.com/sherwood-labs/robinhood-sniper-bot) | Screens new pools with buyer, holder, and deployer checks, with paper trading and backtests. |
| [robinhood-bundler-bot](https://github.com/sherwood-labs/robinhood-bundler-bot) | Launch and buy a token in a single transaction on Pons V2, with simulation and dry-run. |
| [robinhood-volume-bot](https://github.com/sherwood-labs/robinhood-volume-bot) | Prices tokens from Uniswap V3 pools and places bounded swaps. Dry-run by default. |
